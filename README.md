# suse-lolly

The **SUSE brand pack** for [Lolly](https://github.com/lolly-tools/lolly):
SUSE-specific tool definitions plus the SUSE brand catalog (assets, fonts,
design tokens, generated previews/OG cards). Private - see the NOTICE files.

Consumed by the `lolly` monorepo as a git submodule at `brands/suse/`. The
active profile (see the monorepo's `profiles.json`) resolves tool ids across
`community/` in the main repository and `tools/` here (later roots win on an
id collision) and reads `catalog/` here as the catalog root, through
`packages/node-shell/src/content-roots.ts`. There is no repo-root view any more;
`pnpm run profile` prints what is resolved.

```
tools/     # 32 SUSE tool definitions (brand-lockup, pose-geeko, digi-ad, …)
catalog/   # assets/suse/** (incl. tokens/brand.json), fonts/, previews/, og/, tools/index.json
```

- `catalog/tools/index.json` is **generated** by the monorepo's
  `pnpm run build:catalog` (run against the `suse` profile) - do not hand-edit.
- `catalog/assets/suse/tokens/brand.json` is the DTCG design-token document
  generated by `scripts/build-brand-tokens.ts`.
- Logos and dynamic icons remain bundled with the fonts, palettes and tokens.
  Photos, campaign images, executive portraits, backgrounds and illustrations
  come from the organisation's configured Brandfolder connector.
- `catalog/assets/suse/music/` (the PremiumBeat stock-music tracks) was removed
  on 2026-08-29 - no PremiumBeat-licensed audio ships anywhere (see `catalog/NOTICE.md`).

Split out of the public
[`lolly-suse-tools`](https://github.com/lolly-tools/lolly-suse-tools) +
[`lolly-suse-catalog`](https://github.com/lolly-tools/lolly-suse-catalog)
repos (2026-07-08); community-safe tools moved to the public `lolly-tools`
repo.

Licensing is mixed and mostly proprietary - see `tools/NOTICE.md` and
`catalog/NOTICE.md`.

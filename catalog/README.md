# SUSE catalog

Part of the private SUSE brand pack, mounted by
[`lolly`](https://github.com/lolly-tools/lolly) at `brands/suse/catalog/`.

The bundled catalog holds logos, dynamic icons, fonts, palettes, design tokens
and other design-system essentials. The organisation's configured Brandfolder
connector supplies photos, campaign images, executive portraits, backgrounds
and illustrations. Those media files and their catalog entries are not bundled.

Tool/catalog **data**, not code. See `NOTICE.md` for licensing.
